# 📘 Mode d'Emploi - Plateforme Chatbot Service Client

## Bienvenue sur votre plateforme de chatbots intelligents

Cette plateforme vous permet de créer et gérer des agents de service client propulsés par l'intelligence artificielle. Chaque agent peut être personnalisé avec ses propres instructions et sa propre documentation.

**Chaque utilisateur a son propre compte sécurisé.** Vos agents et toutes vos données sont privés et accessibles uniquement par vous, depuis n'importe quel appareil, tant que vous êtes connecté à votre compte.

---

## 🔐 Créer un Compte et Se Connecter

### Première visite : Créer un compte

Lors de votre première visite, vous devez créer un compte :

1. **Accédez à la plateforme** via l'adresse fournie par votre administrateur
2. Vous arrivez sur la page de connexion
3. Cliquez sur **"Créer un compte"** en bas de la page
4. Remplissez le formulaire d'inscription :
   - **Nom complet** : Votre prénom et nom (ex: Jean Dupont)
   - **Email** : Votre adresse email professionnelle
   - **Mot de passe** : Minimum 6 caractères (choisissez un mot de passe sécurisé)
5. Cliquez sur **"Créer mon compte"**

✅ Votre compte est créé ! Vous êtes automatiquement connecté et redirigé vers le tableau de bord.

### Visites suivantes : Se connecter

Pour accéder à nouveau à la plateforme :

1. Rendez-vous sur l'adresse de la plateforme
2. La page de connexion s'affiche
3. Saisissez votre **email** et votre **mot de passe**
4. Cliquez sur **"Se connecter"**

✅ Vous êtes connecté ! Vous retrouvez tous vos agents exactement comme vous les aviez laissés.

### 💡 Bon à savoir

- **Votre session reste active pendant 7 jours** - Vous n'avez pas besoin de vous reconnecter à chaque fois
- **Données privées** - Chaque utilisateur voit uniquement ses propres agents et rapports
- **Accès partout** - Connectez-vous depuis n'importe quel ordinateur ou appareil
- **Déconnexion** - Cliquez sur "Déconnexion" en haut à droite pour vous déconnecter

### ⚠️ Mot de passe oublié ?

Si vous oubliez votre mot de passe, contactez l'administrateur de la plateforme pour réinitialiser votre compte.

## 🤖 Créer un Agent

### 1. Remplir le formulaire

#### **Prompt du Chatbot** (obligatoire)
C'est l'instruction principale que vous donnez à votre chatbot. Définissez son rôle et son comportement.

**Exemples :**
- *"Tu es un assistant service client pour une entreprise de livraison. Tu dois être poli, réactif et aider les clients avec leurs questions sur les colis."*
- *"Tu es un conseiller technique pour une application mobile. Aide les utilisateurs à résoudre leurs problèmes techniques de manière claire et simple."*
- *"Tu es un assistant commercial pour un site e-commerce. Réponds aux questions sur les produits, les prix et les délais de livraison."*

**Conseils :**
- Soyez précis sur le ton à adopter (poli, professionnel, sympathique)
- Indiquez les types de questions que le chatbot doit gérer
- Mentionnez les limites si nécessaire (ex: "Si tu ne sais pas, dis-le clairement")

---

#### **Documentation** (optionnel mais recommandé)

La documentation permet à votre chatbot de répondre avec précision en utilisant vos propres informations.

##### **Option A : Importer des fichiers**

Cliquez sur **"📁 Choisir un fichier"** et sélectionnez vos documents.

**Formats supportés :**
- `.txt` - Fichiers texte
- `.md` - Markdown
- `.csv` - Tableaux CSV
- `.json` - Données JSON
- `.pdf` - Documents PDF
- `.docx` - Documents Word
- `.xlsx` - Fichiers Excel

**Exemples de documents utiles :**
- FAQ de votre entreprise
- Guide produit
- Liste de prix
- Politique de retour
- Procédures internes
- Catalogue de produits

**Vous pouvez ajouter plusieurs documents !** Chaque fichier sera analysé et indexé automatiquement.

##### **Option B : Saisir directement**

Si vous n'avez pas de fichier, vous pouvez coller votre documentation directement dans le champ texte.

**Exemple :**
```
POLITIQUE DE RETOUR
- Retours acceptés sous 30 jours
- Produit en état neuf avec emballage
- Remboursement sous 7 jours ouvrés

DÉLAIS DE LIVRAISON
- France métropolitaine : 2-3 jours
- Europe : 5-7 jours
- International : 10-15 jours

CONTACT
Email : support@example.com
Téléphone : 01 23 45 67 89
```

---

#### **Email pour les rapports** (obligatoire)

Saisissez l'adresse email où vous souhaitez recevoir les rapports d'activité de votre chatbot.

**Exemple :** `responsable@entreprise.com`

---

#### **Couleur du widget** (optionnel)

Choisissez la couleur du widget qui apparaîtra sur votre site web. Cliquez simplement sur la couleur de votre choix parmi les options proposées.

**Couleurs disponibles :**
- Violet (par défaut)
- Noir
- Vert
- Beige
- Bleu
- Rouge
- Marron
- Orange
- Jaune

---

### 2. Créer l'agent

Une fois le formulaire rempli, cliquez sur **"Créer l'Agent"**.

⏳ L'agent est créé et sa documentation est indexée (cela peut prendre quelques secondes si vous avez uploadé des documents volumineux).

✅ Une notification de succès apparaît : votre agent est prêt !

## ✏️ Modifier un Agent

Vous avez fait une erreur ou vous voulez mettre à jour un agent ? C'est simple :

1. Trouvez l'agent dans la liste
2. Cliquez sur **"✏️ Modifier"**
3. Le formulaire s'ouvre avec les informations actuelles
4. Modifiez ce que vous voulez :
   - Changez le prompt
   - Ajoutez ou retirez des documents
   - Modifiez l'email
   - Changez la couleur
5. Cliquez sur **"Créer l'Agent"** pour sauvegarder

**Note importante :** Vous pouvez voir vos documents existants (marqués "📦 existant") et en ajouter de nouveaux. Si vous retirez un document existant, il sera supprimé lors de la sauvegarde.

## 💬 Tester votre Chatbot

Avant d'intégrer le chatbot sur votre site, testez-le directement depuis le tableau de bord :

1. Cliquez sur **"💬 Tester le Chatbot"** sur la carte de l'agent
2. Une interface de chat s'ouvre
3. Posez des questions comme le ferait un vrai client
4. Vérifiez que les réponses sont pertinentes et utilisent bien votre documentation
5. Cliquez sur **"← Retour"** pour revenir au tableau de bord

**Astuce :** Si les réponses ne sont pas satisfaisantes, modifiez votre prompt ou ajoutez plus de documentation !

## 📧 Recevoir des Rapports

Les rapports vous donnent une vue d'ensemble de l'activité de votre chatbot.

### Comment envoyer un rapport

1. Sur la carte de l'agent, cliquez sur **"📧 Envoyer Rapport"**
2. Une fenêtre s'ouvre avec plusieurs options

### Options du rapport

#### **Période du rapport**

##### Option 1 : Toutes les discussions
Sélectionnez **"Toutes les discussions"** pour analyser l'intégralité de l'historique.

##### Option 2 : Entre deux dates
Sélectionnez **"Entre deux dates"** puis choisissez :
- **Date de début** : à partir de quand
- **Date de fin** : jusqu'à quand

**Exemple :** Analyser uniquement les conversations du mois dernier.

---

#### **Sujet du rapport** (optionnel)

C'est une fonctionnalité puissante qui vous permet de **filtrer les conversations par sujet**.

##### **Si vous laissez ce champ vide :**
Le rapport analysera **toutes les conversations** de manière générale :
- Nombre total d'interactions
- Tous les sujets abordés
- Sentiments globaux
- Problèmes généraux

##### **Si vous remplissez ce champ :**
Le rapport se concentrera **UNIQUEMENT** sur les conversations liées à ce sujet spécifique, en ignorant toutes les autres.

**Exemples d'utilisation :**

**Exemple 1 : Analyser les problèmes techniques**
```
Sujet : Problèmes techniques
```
→ Le rapport analysera UNIQUEMENT les conversations où les clients ont signalé des bugs, des erreurs ou des problèmes techniques.

**Exemple 2 : Analyser les réclamations**
```
Sujet : Réclamations et insatisfaction clients
```
→ Le rapport ne montrera que les conversations de clients mécontents ou réclamant.

**Exemple 3 : Analyser les questions sur les prix**
```
Sujet : Questions sur les tarifs et les prix
```
→ Seules les conversations concernant les prix seront analysées.

**Exemple 4 : Suivre un produit spécifique**
```
Sujet : iPhone 15 Pro
```
→ Uniquement les conversations mentionnant ce produit.

##### **Quand utiliser cette fonctionnalité ?**

✅ **Utilisez un sujet spécifique quand :**
- Vous voulez suivre un problème particulier
- Vous lancez un nouveau produit et voulez voir les questions à son sujet
- Vous voulez mesurer l'impact d'un changement (ex: nouvelle politique de retour)
- Vous avez beaucoup de conversations et voulez vous concentrer sur un aspect

❌ **Laissez vide quand :**
- Vous voulez une vue d'ensemble complète
- C'est votre premier rapport
- Vous avez peu de conversations
- Vous voulez voir tous les sujets abordés

---

### Contenu du rapport

Le rapport contient :

1. **Résumé exécutif** - Un paragraphe qui résume l'essentiel
2. **Nombre d'interactions** - Combien de conversations ont eu lieu
3. **Sujets abordés** - Les thèmes principaux avec pourcentages
4. **Sentiments** - Proportion de clients satisfaits/insatisfaits/neutres
5. **Problèmes identifiés** - Les difficultés rencontrées par les clients
6. **Tendances** - Les évolutions remarquables
7. **Recommandations** - Actions suggérées pour améliorer le service

**Le rapport est envoyé par email** à l'adresse que vous avez configurée.

## 🌐 Intégrer le Widget sur votre Site

Une fois votre agent créé et testé, intégrez-le sur votre site web.

### 1. Copier le code

Sur la carte de l'agent, trouvez la section **"Code du Widget"**.

Cliquez sur **"📋 Copier le Code"**.

### 2. Coller sur votre site

Ouvrez le code HTML de votre site web et collez le code juste avant la balise de fermeture `</body>`.

**Exemple :**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Mon Site</title>
</head>
<body>
    <h1>Bienvenue</h1>
    <p>Contenu de votre site...</p>

    <!-- Widget Chatbot -->
    <script>
      window.chatbotConfig = {
        agentId: 1,
        apiUrl: 'https://votre-serveur.com',
        widgetColor: '#667eea'
      };
    </script>
    <script src="https://votre-serveur.com/widget.js"></script>
</body>
</html>
```

### 3. Le widget apparaît

Un bouton de chat apparaît en bas à droite de votre site. Vos visiteurs peuvent cliquer dessus pour discuter avec votre agent !

**Caractéristiques du widget :**
- 💬 Bulle de chat discrète
- 📱 Responsive (adapté aux mobiles)
- ✨ Couleur personnalisable
- 🔄 Textarea auto-resize (s'agrandit si le message est long)
- ⌨️ Shift+Enter pour les sauts de ligne
- 📝 Historique de conversation conservé par session

## 💡 Conseils et Bonnes Pratiques

### Pour un prompt efficace

✅ **Faire :**
- Définir clairement le rôle (ex: "Tu es un assistant service client...")
- Préciser le ton souhaité (poli, professionnel, sympathique)
- Donner des exemples de comportements attendus
- Indiquer quoi faire si l'agent ne sait pas répondre

❌ **Éviter :**
- Les prompts trop vagues ("Aide les clients")
- Les instructions contradictoires
- Les prompts trop longs et complexes

### Pour la documentation

✅ **Faire :**
- Fournir une documentation claire et structurée
- Mettre à jour régulièrement
- Inclure les informations les plus demandées
- Utiliser plusieurs documents si vous avez beaucoup d'infos

❌ **Éviter :**
- Les documents trop longs (découpez-les)
- Les informations obsolètes
- Les formats illisibles

### Pour les rapports

✅ **Faire :**
- Envoyer des rapports régulièrement (hebdomadaire ou mensuel)
- Utiliser le filtre par sujet pour des analyses ciblées
- Lire attentivement les recommandations
- Ajuster votre agent en fonction des retours

❌ **Éviter :**
- Ignorer les rapports
- Ne jamais filtrer par sujet quand vous avez beaucoup de conversations
- Ne pas agir sur les problèmes identifiés

## ❓ Questions Fréquentes

### Combien d'agents puis-je créer ?
Autant que vous voulez ! Chaque agent est indépendant.

### Puis-je avoir plusieurs agents sur le même site ?
Oui, mais en général un seul agent par site suffit. Vous pouvez lui donner une documentation complète.

### Les conversations sont-elles sauvegardées ?
Oui, toutes les conversations sont enregistrées. C'est ce qui permet de générer les rapports.

### Puis-je personnaliser l'apparence du widget ?
Vous pouvez choisir la couleur parmi les options proposées. Pour plus de personnalisation, contactez l'administrateur technique.

### Le chatbot fonctionne-t-il 24/7 ?
Oui ! Tant que votre serveur est en ligne, le chatbot répond à tout moment.

### Que se passe-t-il si le chatbot ne sait pas répondre ?
Le chatbot indiquera honnêtement qu'il ne connaît pas la réponse. C'est pourquoi il est important de fournir une documentation complète.

### Puis-je modifier l'email de réception des rapports ?
Oui, en modifiant l'agent.

### Comment savoir si mon agent fonctionne bien ?
1. Testez-le avec le bouton "Tester le Chatbot"
2. Consultez les rapports régulièrement
3. Vérifiez que les réponses utilisent bien votre documentation

### Les rapports sont-ils automatiques ?
Non, vous devez cliquer sur "Envoyer Rapport" quand vous voulez recevoir un rapport. Cela vous laisse le contrôle sur quand et pour quelle période vous voulez analyser.

### Que signifie "indexation de la documentation" ?
C'est le processus qui permet à l'IA de comprendre et d'utiliser votre documentation. L'IA découpe les documents en petits morceaux et les analyse pour pouvoir les retrouver rapidement quand un client pose une question.

## 🆘 Besoin d'Aide ?

Si vous rencontrez un problème :

1. **Testez d'abord** : Utilisez le bouton "Tester le Chatbot" pour vérifier
2. **Vérifiez le prompt** : Est-il clair et précis ?
3. **Vérifiez la documentation** : Est-elle complète et à jour ?
4. **Consultez les rapports** : Identifiez les problèmes récurrents
5. **Contactez le support technique** : Si le problème persiste

## 🎓 Scénarios d'Usage

### Exemple 1 : Site E-commerce

**Agent :** Assistant Commercial

**Documentation :**

- Rapport "Questions sur les livraisons" pendant les fêtes

---

### Exemple 2 : Service Client SaaS

**Agent :** Assistant Technique
**Prompt :** *"Tu es un conseiller technique pour notre application. Aide les utilisateurs à résoudre leurs problèmes, explique les fonctionnalités et guide-les dans l'utilisation. Si c'est un bug, conseille de contacter le support technique."*

- Guide utilisateur (PDF)
- FAQ technique (texte)
- Liste des bugs connus (Excel)
- Tutoriels vidéo (liens dans un document)

**Rapports :**
- Rapport général hebdomadaire
- Rapport "Problèmes techniques" quotidien
- Rapport "Demandes de fonctionnalités" mensuel

---

### Exemple 3 : Support Après-Vente

- Conditions de garantie (PDF)
